# Inventory

This directory is reserved for inventory files when they need to be separated from broader docs.

Current inventory sources remain at the existing paths until a later cleanup:

| Current file | Owns |
| --- | --- |
| `docs/hardware.md` | Physical hosts and VM sizing baseline |
| `docs/ip-plan.md` | Active, planned, and retired IP assignments |
| `docs/network-inventory.md` | Network-facing systems and planned nodes |
| `docs/storage.md` | Storage classes and storage policy |
| `docs/port-map.md` | Physical port mapping |

Do not duplicate these files here until one source of truth is explicitly moved.
