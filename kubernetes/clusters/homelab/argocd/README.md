# Argo CD Desired State

Argo CD manages this cluster through a root app that points at `argocd/root/`.

Structure:

```text
argocd/
  projects/
  root/
  applications/
```

Use one Argo CD Application per meaningful platform or app domain. Avoid ApplicationSet automation until the manual structure is proven.

Argo CD should manage secret references, not secret values. The selected pattern
is Infisical plus External Secrets Operator. See
`../platform/secrets/README.md` before adding any secret-backed Application.

If this repository is private, Argo CD needs a repository credential in the
`argocd` namespace before the root app can compare or sync. The selected method
is GitHub App authentication through `homelab-yanglianglu`, generated by
External Secrets Operator from Infisical Cloud. Do not commit the credential.

Bootstrap dependency: External Secrets Operator is applied manually once because
Argo CD cannot sync this repository until that generated GitHub App credential
exists. After the credential works, Argo CD should manage the External Secrets
Operator Application and the platform secret resources.
